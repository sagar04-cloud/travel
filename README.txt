TRAVELEASE REACT PROJECT

HOW TO RUN
1. Extract this ZIP file.
2. Open the extracted TravelEase_React_Project folder in VS Code.
3. Open Terminal > New Terminal.
4. Run: npm install
5. Run: npm run dev
6. Open the local URL shown in the terminal, usually http://localhost:5173

FEATURES
- Sign up, sign in and sign out
- Search destinations and filter by travel style and budget
- Sort by price or rating
- Save favourite destinations
- View trip details and book a trip
- See and cancel saved bookings
- Add reviews
- Responsive layout for desktop and mobile
- Browser localStorage keeps demo data after refreshing

IMPORTANT
This is a beginner learning project. Authentication and data are stored in the browser,
so this is NOT secure enough for a real public website. For production, use a backend
and a proper authentication provider such as Firebase Authentication or Supabase Auth.
